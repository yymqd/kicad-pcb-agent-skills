# PCB 设计审查清单（7 层系统检查法）

交付前逐层执行，不跳层，不凭记忆。

---

## 第 1 层：每颗 IC 每个引脚的电压/电流

**核心问题**：TLV2371 V+=9.5V>5.5V（供电超 ABS MAX），SGM6601 EN=9.5V>6V（使能脚超 ABS MAX）。都是同一类错误：**装 IC 前没查数据手册的 Absolute Maximum Ratings。**

| 检查项 | 方法 | 工具 |
|:-------|:-----|:-----|
| 供电电压 < ABS MAX | 数据手册 Absolute Maximum Ratings 对照设计值 | 手动查 |
| 输入引脚电压 < ABS MAX | 每个引脚：外接电压是否在允许范围内 | 手动查 |
| 输出引脚电流 < 额定值 | 输出驱动能力是否满足负载需求 | 手动查 |
| ENABLE/SHDN 引脚电压 | 使能引脚电压有单独的 ABS MAX，不一定跟 VCC 一样 | 手动查 |

**如何不漏**：对每颗 IC，把每个引脚的网络名和电压写在一行，然后逐行对数据手册。

---

## 第 2 层：每只晶体管的封装引脚 vs 数据手册

**核心问题**：2N7002 和 MMBT3904 的 SOT-23-3 焊盘编号全部分配错误——因为写 `sot23()` 辅助函数时随意定了 pin 顺序，没去对 KiCad 标准封装的实际 pad 编号和器件数据手册的引脚定义。

**方法**：

```python
# KiCad SOT-23-3 标准焊盘位置
# Pad 1: (-1.137, -0.950)  # 根据 KiCad 封装确定
# Pad 2: (-1.137, 0.950)   # 根据 KiCad 封装确定
# Pad 3: (1.137, 0.000)    # 根据 KiCad 封装确定

# 2N7002 数据手册引脚定义: 1=Gate, 2=Source, 3=Drain
# → 对应关系: Pad1=Gate, Pad2=Source, Pad3=Drain
# → 焊盘分配: GATE→Pad1, GND→Pad2, DRAIN_SIGNAL→Pad3

# MMBT3904 数据手册引脚定义: 1=Base, 2=Emitter, 3=Collector
# → 对应关系: Pad1=Base, Pad2=Emitter, Pad3=Collector
```

**操作步骤**：
1. `FootprintLoad()` 加载 KiCad 标准封装
2. `list(fp.Pads())` 查看 pad 编号和位置
3. 对照器件数据手册的引脚定义图（在 SOT-23 上通常有标记）
4. 创建引脚对照表：`Pad1=功能, Pad2=功能, Pad3=功能`
5. 确保 `SetNet()` 时用对了 pad 编号

**常见 SOT-23 器件引脚定义**：

| 器件 | Pad1 | Pad2 | Pad3 |
|:-----|:-----|:-----|:-----|
| 2N7002 (N-MOSFET) | Gate | Source | Drain |
| MMBT3904 (NPN) | Base | Emitter | Collector |
| MMBT3906 (PNP) | Base | Emitter | Collector |
| BSS138 (N-MOSFET) | Gate | Source | Drain |

## 第 3 层：每个阻容感的应力

| 检查项 | 计算公式 | 标准 |
|:-------|:---------|:-----|
| 电阻功率 | I²×R | < 封装额定 × 0.8 |
| 电容耐压 | Vmax_applied × 1.5 | < 额定电压 |
| 电感饱和电流 | I_peak (含纹波) | < I_sat × 0.8 |

**案例**：RS(15Ω, 0.2A) → 0.6W。0805 额定 0.125W→不够，2512(1W)→有余量。

---

## 第 4 层：核心电路参数

| 检查项 | 方法 |
|:-------|:------|
| Boost 电感值 | 按数据手册公式：L = Vin×(Vout-Vin)/(ΔI×fsw×Vout) |
| 反馈分压 | Vout = Vfb × (1+Rtop/Rbot)，用实际电阻值代入 |
| 恒流设定 | I = Vref / Rsense |
| 补偿网络 | 反馈环是否有补偿电容（高增益运放需 Ccomp） |

---

## 第 5 层：每个外部接口的保护

| 接口 | 保护类型 |
|:-----|:---------|
| 电源输入 | ESD + 过压 + 反接 |
| 信号输入 | ESD + 上拉/下拉（浮空时确定态） |
| 负载输出 | ESD + 反接 |

**TTL 接口检查重点**：
- 浮空时 LD 应该 ON（CW 模式）→ TTL 需要上拉
- 上拉电压源在板上要存在（本例：VIN=5V）

## 第 6 层：可制造性

| 检查项 | JLCPCB 标准 |
|:-------|:------------|
| 最小线宽 | 0.1mm |
| 最小间距 | 0.1mm |
| 最小过孔 | 0.3mm drill |
| 最小元件间距 | 0.3mm（0603 之间）|
| 板厚 | 1.6mm 标准 |

**载流能力参考（1oz 铜，10°C 温升）**：
| 线宽 | 载流 |
|:-----|:-----|
| 0.3mm | ~0.5A |
| 0.5mm | ~0.8A |
| 1.0mm | ~1.5A |

## 第 7 层：网络完整性

- [ ] 每个 net 至少 2 个焊盘（除 NC 外）
- [ ] 无意外悬空引脚（安装孔无网络是正常的）
- [ ] DRC 报告的 unconnected items 逐个审查
- [ ] DRC 报告的 violations 按类型分布审查（短路项必须清零）
